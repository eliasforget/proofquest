# Paysage concurrentiel — notes initiales

Ce document n'est **pas une étude exhaustive**. Il sert à ne pas raisonner comme si le concept existait dans le vide.

## Ce qu'il faut rechercher avant le lancement

Pour chaque concurrent :

- cible ;
- prix ;
- onboarding ;
- source des données ;
- comment il prouve une compétence ;
- rétention ;
- partage ;
- avis négatifs récurrents.

## Angle à défendre

ProofQuest n'a pas besoin d'être le premier. Il doit devenir le produit où **la preuve est aussi agréable à explorer que la progression dans un jeu**.
