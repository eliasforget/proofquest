# Commencer ProofQuest

## Notre première victoire

Ne pas viser immédiatement un SaaS complet. La première victoire est plus simple :

> Un développeur connecte GitHub, choisit un dépôt et obtient en moins de deux minutes un résultat suffisamment beau et utile pour vouloir le partager.

## Démo déjà incluse

Ouvrir `../prototype/index.html` dans Chrome, Edge ou Firefox. Le prototype est autonome : aucun serveur ni compte n'est nécessaire.

Le bouton **Analyze my GitHub** simule le parcours jusqu'au dashboard. Les données sont volontairement fictives et marquées comme démo.

## Ensuite

Ordre conseillé :

1. faire tourner `app/` localement ;
2. transformer l'écran de dashboard en composants propres ;
3. implémenter une connexion GitHub en lecture seule ;
4. récupérer uniquement les signaux nécessaires d'un dépôt ;
5. produire un premier rapport déterministe sans IA ;
6. ajouter une couche IA pour synthèse et quêtes ;
7. rendre un profil public partageable ;
8. tester avec 10 puis 30 développeurs.

## Définition de "ça marche"

Avant tout paiement, chercher ces signaux :

- des inconnus terminent l'analyse ;
- une part significative partage son profil ou copie son lien ;
- des utilisateurs reviennent consulter une quête ou réanalyser un dépôt ;
- certains demandent spontanément des fonctions plus avancées ;
- le bouton d'intérêt Pro reçoit des clics sans promesse trompeuse.
