# Roadmap

## Phase 0 — Fondation — maintenant

- documents produit ;
- prototype visuel ;
- squelette Next.js ;
- backlog et architecture.

## Phase 1 — Vertical slice

- vraie auth GitHub ;
- 1 dépôt public ;
- détecteur TypeScript / React / tests / Docker / CI ;
- dashboard réel ;
- aucune IA nécessaire pour les scores.

**But :** obtenir une vraie analyse de votre propre repository.

## Phase 2 — Intelligence utile

- sorties IA structurées ;
- synthèse de preuves ;
- 3 quêtes personnalisées ;
- garde-fous anti-hallucination : l'IA ne peut utiliser que les preuves passées en entrée.

## Phase 3 — Beta 10

- 10 testeurs externes ;
- corriger onboarding et erreurs ;
- chronométrer time-to-value ;
- entretiens courts asynchrones possibles, formulaire intégré.

## Phase 4 — Beta 30/50

- profils publics ;
- partage ;
- mesure rétention ;
- page d'intérêt Pro non payante.

## Phase 5 — Décision

Trois issues acceptables :

- **accélérer** si usage/retour forts ;
- **pivoter** si le besoin existe mais le format ne colle pas ;
- **arrêter** si l'intérêt réel reste faible.

Créer la structure commerciale appropriée avant de passer à une activité rémunérée récurrente.
