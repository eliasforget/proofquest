# MVP — Périmètre verrouillé

## Ce que nous construisons

### Écran 1 — Landing
Promesse, aperçu du skill tree, CTA GitHub, mini preuve sociale uniquement lorsqu'elle sera réelle.

### Écran 2 — Repository picker
Connexion + sélection d'un dépôt.

### Écran 3 — Analysis sequence
Progression animée montrant les étapes de manière honnête.

### Écran 4 — Dashboard
Skill graph, statistiques, preuves, quêtes, partage.

## Premier moteur de compétences

Compétences P0 :

- JavaScript / TypeScript
- React / Next.js
- Node.js
- SQL / PostgreSQL
- Testing
- GitHub Actions / CI
- Docker
- Documentation

N'ajouter une compétence que si nous savons définir des signaux observables raisonnables.

## Données fictives du prototype

Le prototype fourni contient un profil `ELIAS / BUILD #A17` totalement fictif. Il sert uniquement à matérialiser la direction artistique. Il ne doit jamais être présenté comme une vraie analyse.

## Définition de Done

- parcours réalisable de bout en bout ;
- aucune fausse preuve ;
- mobile acceptable ;
- temps de chargement raisonnable ;
- erreurs GitHub compréhensibles ;
- instrumentation de quatre événements : `connect_started`, `repo_selected`, `analysis_completed`, `profile_shared`.
