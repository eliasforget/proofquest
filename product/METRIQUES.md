# Métriques

## North-star provisoire

**Profils utiles créés par semaine**, où "utile" = analyse terminée + au moins une interaction avec une preuve ou une quête.

## Funnel

1. landing viewed
2. connect started
3. auth completed
4. repo selected
5. analysis completed
6. evidence opened
7. quest opened
8. profile shared
9. returned within 7 days

## Métriques à surveiller

- time-to-first-result ;
- taux d'échec GitHub ;
- coût moyen par analyse ;
- taux de partage ;
- réanalyse à J+7/J+30 ;
- demandes spontanées de fonctions payantes.

## Pas de vanity metrics

Les impressions sociales ne valent pas une activation produit. Préférer les actions montrant un effort réel de l'utilisateur.
