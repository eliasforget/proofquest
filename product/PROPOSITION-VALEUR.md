# Proposition de valeur

## Formule courte

**Turn your code into proof.**

## Pour l'utilisateur

Au lieu d'une liste auto-déclarée de compétences, obtenir une carte visuelle reliée à des preuves observables et à des prochaines actions.

## Différenciation recherchée

La combinaison :

```text
Repository evidence
      +
Skill graph
      +
Progression / quests
      +
Shareable identity
```

Aucun de ces éléments pris seul n'est nouveau. La valeur doit venir de l'intégration et de l'exécution.

## Ce que le produit ne promet pas

- garantir un emploi ;
- mesurer scientifiquement l'intelligence ou la valeur d'un développeur ;
- remplacer un entretien technique ;
- connaître ce qui n'apparaît pas dans le code analysé.
