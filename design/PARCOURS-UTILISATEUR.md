# Parcours utilisateur

## Happy path

```text
Découverte
  ↓
"Je veux voir ce que mon GitHub dit de moi"
  ↓
Connexion GitHub
  ↓
Choisir mon meilleur repo
  ↓
Voir l'analyse progresser
  ↓
Découvrir mon skill graph
  ↓
Cliquer une compétence
  ↓
Comprendre les preuves
  ↓
Choisir une quête
  ↓
Partager mon profil
```

## Moments à optimiser

### Moment 1 — Confiance
Avant OAuth : expliquer exactement ce qui sera lu.

### Moment 2 — Attente
Pendant l'analyse : montrer de vraies étapes, pas une fausse barre arbitraire.

### Moment 3 — Surprise
Le premier dashboard doit présenter immédiatement 1–2 observations intéressantes.

### Moment 4 — Action
Toujours donner un prochain pas concret.

### Moment 5 — Fierté
Le profil partagé doit être beau même si le niveau est débutant.
