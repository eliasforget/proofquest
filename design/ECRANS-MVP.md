# Écrans MVP

## 01 — Landing

Hero : "Turn your code into proof."  
Sous-titre : "ProofQuest maps evidence from your repositories into a living skill graph and your next technical quests."  
CTA principal : `Analyze my GitHub`.

## 02 — Repo picker

Titre : `Choose the build that represents you.`  
Cartes dépôt avec stack et activité récente.

## 03 — Analyse

Scanner central + flux d'événements :

- `package.json discovered`
- `TypeScript strict mode detected`
- `CI workflow found`
- `12 test files mapped`

Afficher uniquement des événements réellement trouvés lorsque le moteur sera branché.

## 04 — Dashboard

Colonne gauche : identité + catégories.  
Centre : constellation de skills.  
Droite : quête active + preuves récentes.

## 05 — Détail skill (drawer)

Nom, progression, liste des preuves, limites de l'analyse, prochain unlock.
