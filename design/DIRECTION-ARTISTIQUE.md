# Direction artistique — "Career Observatory"

## Intention

Éviter le cliché "jeu médiéval". ProofQuest doit ressembler à un mélange entre :

- observatoire spatial ;
- terminal développeur haut de gamme ;
- arbre de progression de jeu AAA ;
- interface de diagnostic scientifique.

## Signature

Fond presque noir, lumière froide, halos violets/bleus, grilles très discrètes, cartes en verre sombre, typographie technique, animations lentes.

Le skill tree n'est pas une liste : c'est une **constellation de preuves**.

## Motion

- lignes qui s'allument lorsqu'une compétence est reliée ;
- pulsation légère des noeuds débloqués ;
- scan vertical pendant l'analyse ;
- compteurs courts, jamais casino ;
- transitions de 180–450 ms.

## Ton

Précis et ambitieux. Éviter les affirmations du type "Vous êtes expert". Préférer :

- "Strong evidence detected"
- "3 signals found"
- "Next unlock"
- "Built with proof"
